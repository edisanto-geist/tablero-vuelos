# Logos de aerolíneas

En Fase 1 no se suben logos: el tablero usa una insignia de color con el código IATA.

Hook para más adelante: poné un `logos/<ICAO>.png` (por ejemplo `ARG.png`, `JAT.png`) y activá
`USAR_LOGOS_PNG: true` en `config.local.js`. Si falta el archivo, el tablero vuelve solo a la insignia.
Verificá la licencia de cada logo antes de usarlo.
